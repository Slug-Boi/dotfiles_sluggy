# Arch

This branch is going to be the new starting point for my dotfiles on Linux. After a couple of years of using NixOS it has just become too much of a hassle to maintain and use. I have for the past 6 months felt dread when thinking about booting up my main Linux distro due to knowing I would need to spend a full day each time to try and get back to a somewhat stable point. Package management for tools is cool through Nix, OS package management is not so much. I want to try CachyOs, which will let me get back to my arch roots without having to deal with all the annoying initial parts. This ReadMe will be updated as I flesh out the system and hopefully get to once again enjoy Linux rather than fight my package manager 3 times a week. My mac will keep running Nix.
